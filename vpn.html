Where do I get a server?

  • Your own server (best): with any cheap VPS, run ssh -D 1080 user@your-server in Terminal, then use SOCKS5, server 127.0.0.1, port 1080.
  • A VPN provider that includes a proxy: many paid services give you an HTTP or SOCKS5 address and login. Use it here.
  • Avoid random free proxy lists. The operator can read or tamper with your traffic.

Good to know

  • This is a proxy for this browser only, not a system-wide VPN. Other apps aren't covered.
  • Chromium can't send a username/password to SOCKS5. If your provider needs a login, choose HTTP or HTTPS.
  • If the server goes down while this is on, pages fail to load instead of silently using your real IP.
  • Want system-wide coverage? Install a VPN app like Proton VPN Free.
